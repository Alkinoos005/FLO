# FLOPPY CUBE
A fun game i created inspired by floppy bird but with my own twist!
Here's the guide and the inspo behind the idea of it's creation.

Growing up, I was always curious about how digital worlds worked behind the glass of a screen. Like many kids, my first real introduction to interactive technology wasn’t a lecture or a textbook, it was a video game.I vividly remember playing Flappy Bird, a game so ridiculously simple in its design yet impossibly addicting. You tapped a screen,so that a pixelated bird flapped its wings and it would fly, you tried to dodge endless columns of green pipes. It seemed simple on the surface, but playing it sparked a deeper question in my mind: How does a computer actually know when the bird hits a wall, and how can I build something like that myself?

That curiosity got the best of me and it led me straight into the world of web development, starting with HTML. At first, learning HTML felt like discovering a secret language. I learned that HTML (HyperText Markup Language) is not a programming language that handles complex math or logic, but rather the essential skeleton of every website. It relies on elements called "tags" to structure content on a page. For instance, putting text inside <p> tags defines a paragraph, while <h1> creates a bold title. Learning how these tags organized plain text into structured, visual pages was instantly rewarding.

HTML it is. I hope you enjoy playing it and having as much fun as I did in the creating process and in the playing/Testing time ( It was fabulous).

You'll find some secret passwords and some interesting design smart adjustments from a begginer HTML programmer. Have fun and give me your opinion on it so I can fix it and become better at it.
